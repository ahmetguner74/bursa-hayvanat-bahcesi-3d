# 36 Sülün Kuşları

Resmî 2026 krokisindeki `36` numaralı yaşam alanı. Krokiler ve araştırma fotoğrafları `kaynaklar/` altında; URL, yükleme tarihi ve dosya özeti `kaynaklar/kaynakca.json` içinde. Fotoğrafın yükleme tarihi çekim tarihi olmayabilir. M5/DGN eski durumdur; mevcut geometri için doğrudan kabul edilmez. `model/` alanı düzenlenebilir 3B varlıklar içindir.
