# 43 Acil Çıkış Noktaları

Resmî 2026 krokisindeki `43` numaralı güvenlik. Krokiler ve araştırma fotoğrafları `kaynaklar/` altında; URL, yükleme tarihi ve dosya özeti `kaynaklar/kaynakca.json` içinde. Fotoğrafın yükleme tarihi çekim tarihi olmayabilir. M5/DGN eski durumdur; mevcut geometri için doğrudan kabul edilmez. `model/` alanı düzenlenebilir 3B varlıklar içindir.
